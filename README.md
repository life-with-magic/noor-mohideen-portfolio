# Noor Mohideen — Portfolio

This repository contains the full source code for Noor Mohideen's editorial portfolio website. The primary application lives in the **`portfolio/`** subdirectory.

- **Directory structure**:
  - `portfolio/` – React + Tailwind CSS + Framer Motion application.
  - `portfolio/src/data/resume.yaml` – Single source of truth for all bio and project data.
  - `portfolio/public/` – Static assets (images, fonts, etc.).

## Quick start (global)
```bash
# Clone the repo
git clone https://github.com/life-with-magic/noor-mohideen-portfolio.git
cd noor-mohideen-portfolio

# Navigate to the portfolio subfolder
cd portfolio
npm install
npm run dev
```

The application will be available at `http://localhost:5173/`.
